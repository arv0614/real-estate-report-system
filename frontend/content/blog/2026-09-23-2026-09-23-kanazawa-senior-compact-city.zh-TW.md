迎接2026年9月的敬老之日，放眼「人生百年時代」的未來居住型態，再次成為大眾矚目的焦點。特別是對於開始對開車感到不安的銀髮族而言，能在步行範圍內解決生活所有需求的環境，絕對是不可或缺的。因此，目前在不動產市場上備受矚目的，正是石川縣金澤市 (石川県金沢市) 強力推動的「緊湊城市戰略 (Compact City)」，以及隨之而來的「市中心居住」推廣計畫。

隨著北陸新幹線延伸至敦賀 (Tsuruga)，金澤市的都市機能正快速升級。從金澤車站周邊延伸至片町 (Katamachi) 的「都心軸」區域，已被國家指定為都市再生緊急整備地區，老舊大樓的重建與大規模都市更新正在多處同時進行。隨著醫療機構與商業設施集中於市中心，這裡不僅是銀髮族安度晚年的理想居所，也正蛻變為注重生活便利性的育兒家庭與單身族群眼中極具吸引力的區域。

本文將從專業不動產分析師的角度，結合日本國土交通省的公開交易數據與最新市政動態，深入解析金澤市中心區域「市中心居住」的真正價值，以及都市更新所帶來的未來資產增值潛力。無論是正在考慮購買自用住宅的剛性需求者，還是放眼未來的不動產投資人，我們都將為您揭曉為何「現在」應該關注金澤市中心的原因，並分享零失敗的選屋秘訣。

## 1. 在2026年敬老之日探討「未來的居住型態」與銀髮族需求的轉變

| 投資與自住潛力的結論與根據 |
| :--- |
| 綜合評估：無論是作為自住的晚年居所，或是著眼於未來資產價值的投資標的，皆具備「極高潛力」 |
| 根據① 都市更新：邁向2028～2030年，金澤站前與武藏辻 (Musashigatsuji) 的大型複合式大樓建設將全面啟動 |

開門見山地說，2026年目前的金澤市中心商業區（都心軸區域），是一個未來資產價值有望保值甚至增值的高度潛力市場。其最大原因在於，銀髮族的「換屋需求」與地方政府強力的「居住引導政策」達成了完美的契合。

隨著高齡化社會的發展，銀髮族從郊區寬敞的透天厝，縮減居住空間（換屋）搬遷至市中心高便利性電梯大樓的趨勢，未來將進一步加速。減輕庭院維護與冬季剷雪的負擔，即使不再開車，光靠步行或大眾運輸工具就能輕鬆前往醫院、超市與文化設施，這種「市中心」的生活環境，具有無可取代的價值。

這種強勁的剛性需求（實際居住需求），對不動產投資人來說也至關重要。因為可以預期穩定的租賃需求與未來的轉手市場，進而降低空置風險與價格下跌的風險。在銀髮族需求的支撐下，預計金澤市中心的房地產價值在邁向2030年代時，將進一步顯現其溢價優勢。

## 2. 金澤市推動的緊湊城市戰略與「市中心居住」現況

| 調查目標區域：石川縣金澤市（緯度36.561325, 經度136.656205周邊區域） |

金澤市將「保存與開發的協調」列為城市建設的基本方針，並將從金澤港經由金澤車站延伸至片町的幹道定位為「都心軸」。沿著這條軸線將商業、辦公與居住機能集中發展的緊湊城市戰略，目前正逐漸開花結果。

值得注意的是，金澤市獨自推出的一系列優渥居住支援政策。以具代表性的「金澤市市中心・居住引導區域住宅取得獎勵金」為例，若在市中心的「街區」購買透天厝或電梯大樓（新建或購入），將補助一定比例的貸款金額（包含對育兒家庭與移居者的加碼，最高可達200萬日圓）。此外，還有最高50萬日圓的「金澤市地區計畫區域等住宅取得獎勵金」，由此可見政府推動人口回流市中心的決心。

從這次透過 Mekiki Research 取得的實際數據來看，該區域的土地使用分區被劃定為「商業區」，是建蔽率高達80%、容積率400%的高強度利用區域。因為能有效利用有限的土地興建中高層住宅大樓與複合式商辦，對不動產開發商而言極具開發誘因。其結果是，更容易供應符合銀髮族需求、具備無障礙設施的優質住宅物件，進而形成理想的良性循環。

## 3. 醫療機能與商業設施集中！市中心都市更新帶來的極致居住便利性

| 支撐居住便利性的醫療與都市更新數據 |
| :--- |
| 周邊醫療機構數量：24家（包含 伊藤醫院 (伊藤病院)、川北眼科診所 (かわきた眼科クリニック)、佐武診所 (さぶりクリニック) 等） |
| 2026年5月：金澤站西口將動工興建日本海側首座大型展演空間「Zepp金澤（暫定名稱）」 |
| 2026年8月：武藏辻區域3棟高約60公尺的高層大樓都市更新計畫獲審議會通過 |
| 2028～2030年左右：金澤站東口的前金澤都飯店 (旧金沢都ホテル) 舊址，將正式推動160公尺級的官民複合大樓構想 |

對銀髮族而言，評估「居住便利性」最重要的指標，絕對少不了完善的醫療機構。根據本次取得的數據，目標區域周邊竟有多達24家醫療機構。從規模較大的「伊藤醫院」，到「川北眼科診所」、「佐武診所」等專科診所，皆密集分佈於步行範圍內。這不僅方便日常的健康管理，遇到突發急病時也能提供極大的安心感。

此外，在金澤市的都心軸區域，包含支援日常採買的商業設施在內，大規模的都市更新正在同步進行中。隨著2024年7月從金澤站到片町的區域被國家指定為「都市再生緊急整備地區」，老舊大樓拆除費用補助等稅賦優惠正式啟動，街區的活化與年輕化正急速推進。

2026年8月，鄰近近江町市場 (Omicho Market) 的武藏辻區域（金澤天空大樓 (金沢スカイビル) 周邊），一項包含低樓層商業設施、高樓層為飯店與住宅，共3棟高約60公尺的高層大樓建設計畫已獲得都市計畫審議會的核准。此外，長年閒置的金澤站東口前金澤都飯店舊址，近鐵不動產 (近鉄不動産) 已宣布將打造一棟高達160公尺、具備MICE（會展產業）機能、奢華飯店與住宅空間的日本海側第一指標性複合大樓構想。

隨著2028年至2030年這些都市更新項目陸續完工，當地的生活便利性將迎來飛躍性的提升。從不動產投資的法則來看，趁著都更藍圖已經描繪完畢、正準備動工的「現在」，正是房價全面上漲前進場布局的最佳時機。

## 4. 不只是銀髮族？追求便利性的家庭與單身族群也趨之若鶩的理由

| 金澤市市中心教育與育兒支援數據（2026年最新） |
| :--- |
| 指定學區：犀櫻小學 (犀桜小学校)、城南中學 (城南中学校) |
| 育兒應援津貼：每名兒童發放3萬日圓（中央2萬日圓＋市府額外加碼1萬日圓） |
| 減輕托育負擔：未滿3歲之第二胎托育費用全免（2025年度起實施） |

聽到「市中心居住」，人們往往會認為這是銀髮族的專利，但事實上，近年來這裡在20代～40代的育兒家庭與單身商務人士中的受歡迎程度正急遽上升。其最大原因在於金澤市推出的豐厚育兒支援制度，以及優良的教育環境。

作為2026年的最新動態，為因應物價上漲，金澤市針對每名兒童發放3萬日圓（國家2萬日圓加上市府獨自加碼1萬日圓）的「抗通膨育兒應援津貼」。此外，包含未滿3歲之第二胎托育費用全免，以及陪伴型孕產婦支援計畫等，經濟上的支持措施十分完善。

在教育環境方面，目標區域屬於「犀櫻小學」與「城南中學」的學區。金澤市是日本全國學力名列前茅的教育大縣，市中心的學校往往容易吸引注重教育的家庭聚集。因此，越來越多家庭為了追求良好的教育環境，刻意選擇在「市中心」購買住宅大樓。

此外，對於單身族群而言，能夠實現「職住相鄰」的市中心同樣極具吸引力。在當今重「質（時間與體驗）」勝於「量（空間大小）」的生活型態下，金澤市中心已成為吸引各個世代的強力磁鐵。

## 5. 零自駕也能舒適生活的交通路網與步行生活圈的魅力

| 交通基礎設施與娛樂設施的完善度 |
| :--- |
| 最近車站數據：在公開交易數據上顯示為 null（以不依賴鐵路車站、獨自發展的公車與道路路網為特徵） |
| 大眾運輸工具：以金澤站為起點的豐富公車路線網，以及完善的共享單車系統 |

日本地方城市面臨的最大課題就是「擺脫汽車社會」，但單就金澤市的都心軸區域而言，即使不買車，也能享受十分舒適的生活。

在本次取得的日本國土交通省公開交易數據中，目標區域的最近車站相關資訊（站名與進出站人數）顯示為「null（無數據）」。這並非數據缺失，而是真實反映了金澤市中心並非依靠全國劃一的「鐵路車站步行圈」指標，而是憑藉其獨特且高度發展的公車路網繁榮起來的城市特性。以金澤站為樞紐，每隔幾分鐘就有公車巡迴前往香林坊 (Korinbo)、片町與武藏辻。加上地形平坦，使用共享單車也非常方便，因此相較於與車站的距離，「與主要公車站牌的距離」更能左右當地的資產價值。

即使年老後繳回駕照，依然能步行到近江町市場採買新鮮食材，或是前往常看的診所就醫。這種「可以步行生活的城市」的實現，正是緊湊城市戰略的精髓。此外，預計2027年秋季金澤站西口將迎來「Zepp金澤（暫定名稱）」的完工，年輕族群與單身者無需遠行，就能在本地享受最前端的音樂娛樂體驗。

能夠省下維持兩部車的開銷（每年數十萬日圓），並將這筆預算轉用於繳納房貸、投資或教育費用，對剛性需求族群來說，絕對是非常合理的選擇。

儘管金澤市的市中心居住充滿魅力，但在挑選物件時，有一點是絕對不能妥協的，那就是「對自然災害風險的防範」。

因此，要挑選能長久安心居住的優質物件，鐵則如下：
1. 若選擇電梯大樓，請挑選2樓以上（最好是3樓以上）的戶型：萬一發生淹水，也能保護居住空間與珍貴的家當。
2. 確認建築物電氣設備（受變電設備）的位置：若電氣設備設於地下室，淹水時恐將面臨全棟停電、停水的風險。請選擇將設備配置於1樓較高處或高樓層的物件。
3. 避開土石流警戒區域：務必確認災害潛勢地圖，靠近山坡地或懸崖的物件，即使價格較便宜，也必須謹慎評估。
